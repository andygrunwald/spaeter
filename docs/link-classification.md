# FAQ: How links are classified

|--------|------------------------------------------------------------------------------------|
| Watch  | YouTube, Vimeo, Twitch, ARD Mediathek                                              |
| Listen | Spotify (always, including video podcasts), Apple Podcasts, Overcast, Pocket Casts |
| Read   | everything else                                                                    |
